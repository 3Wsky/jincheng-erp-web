# 锦程 ERP 整体界面与模块框架

## 1. 文档状态

- 状态：`VERIFY`
- 更新日期：2026-08-10
- 范围：网站端统一界面、信息架构、经营工作台、货品中心接入和其他模块占位框架。
- 边界：本文件只确认产品界面与路由结构，不确认销售、库存、资金、成本、权限和业绩的最终业务规则。

## 2. 产品定位

锦程 ERP 网站端采用企业级后台工作区结构，以“高信息密度、清晰状态、业务可信、跨模块一致”为设计目标。页面不能用展示型官网风格代替后台操作效率，也不能用虚构经营数据制造完成假象。

统一框架包括：

1. 深色主导航：承载经营、进销存、客户、财务、组织和系统模块。
2. 顶部工具栏：提供全局搜索、快捷新建、消息入口、组织和账号信息。
3. 经营工作台：展示真实数据源扫描结果、模块实施进度、快捷入口和待确认事项。
4. 业务工作区：所有模块继承统一的标题、面包屑、状态、卡片、表格和反馈组件。
5. 移动端导航：960px 以下使用抽屉式导航；390px 页面不得产生整体横向滚动。

## 4. 视觉与交互标准

- 主色使用稳健蓝色，深色侧栏用于建立企业软件识别度；成功、警告、危险状态使用固定语义色。
- 内容卡片采用小圆角、浅边框和克制阴影，避免大面积装饰影响数据阅读。
- 桌面端优先在 1366×768 下保证菜单、标题、首屏指标和主要操作可见。
- 手机端保留业务层级，操作按钮改为全宽，复杂表格在自身容器内横向滚动。
- 页面必须区分“真实可用”“下一阶段”“规划中”“待业务确认”，占位模块不得显示伪造订单、金额或库存。

## 5. 货品模块接入

货品中心继续使用已实现的商品、SKU、条码和管家婆 CDS 预校验接口，并统一接入 ERP 外壳。以下安全边界保持不变：

- 管家婆导入先生成预校验批次和待归类商品。
- 异常行和重复串号保留在错误清单。
- 仓库映射、成本和入库时间未确认前，不生成库存余额和库存流水。
- 后端或数据库不可用时，页面显示中文可操作提示，不白屏。
