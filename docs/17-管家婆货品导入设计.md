# 管家婆货品导入设计

## 1. 权威数据源

- 管家婆辉煌Ⅱ主库位于远程 SQL Server，并通过私有 socket 提供给客户端；ERP 不破解私有协议，也不使用 `sa` 凭据直连。
- 智储星项目已经验证 `table_m.cds` 是本机序列号库存缓存，字段为：行号、仓库编号、仓库全名、编号、商品全名、序列号。
- ERP 通过环境变量 `GRASP_CDS_FILE` 配置 CDS 的固定路径。API 不接受调用方提交任意文件路径，避免越权读取本机文件。
- 智储星历史 SQLite 已具备管家婆归档模型，但在本次检查时尚无 `GRASP` 批次，因此当前以 CDS 为实际来源；后续 SQLite 有正式批次后可增加只读适配器。

## 3. 导入流程

1. API 只读加载固定 CDS，限制最大 50MB。
2. 计算 SHA-256 内容哈希；相同文件返回原批次，不重复暂存。
3. 解析字段并校验缺失编码、名称、仓库、串号、重复串号和同编码多名称。
4. 原始文件写入 `CatalogImportDocument`，解析事实写入 `CatalogImportBatch/CatalogImportRow`；错误行保留错误码，不静默丢弃。
5. 应用批次时，以 `GRASP + 货品编号` 建立外部身份；新商品标记为“待归类”。
6. 商品/SKU、审计日志和 outbox 事件在同一事务内提交。
7. 仓库映射、成本和收货时间未确认前，库存写入数量固定为 0。

## 4. 字段映射

| 管家婆字段    | ERP 暂存字段               | ERP 正式字段                                | 规则                                     |
| ------------- | -------------------------- | ------------------------------------------- | ---------------------------------------- |
| 编号          | `sourceSkuCode`            | `Product.code`、`Sku.code`、外部 `sourceId` | 原样保留，禁止重复                       |
| 商品全名      | `sourceName`               | `Product.modelName`、`Sku.name`             | 先作为待归类名称，不猜品牌/品类          |
| 仓库编号/全名 | `sourceWarehouseCode/Name` | `Warehouse.code/name` | 68 类真实分类已解析（见 17a），类型归属待签字 |
| 序列号        | `sourceSerial`             | 暂不落 `SerialItem`                         | 等待仓库、成本、收货时间后再生成单机档案 |
| 每行一台      | `quantity=1`               | 暂不生成库存流水                            | 库存必须由迁移单据驱动                   |

## 5. 安全与回滚

- 预览和应用均不修改管家婆或智储星文件。
- 生产写接口未配置保护密钥时默认关闭；完整 RBAC 接入前不得上线。
- 批次应用不物理删除历史；代码回滚后保留批次和审计，修复使用前向迁移或冲销方案。
- 正式库存迁移前必须先确认仓库映射、单机成本、收货时间和期初单据类型，并在 staging 对账演练。
