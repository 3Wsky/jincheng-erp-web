## 3. 如何核对真实进度（每次接手先做这个）

```bash
pnpm progress                 # 只读体检：SQL + HTTP + 端到端业务动作
pnpm progress -- --write      # 追加写链路探测（创建 PROBE- 探针商品后停用）
```

- 输出 `progress-report.html`（模块看板 + 链路图 + 接口对照）和 `progress-report.json`。
- 每个绿点都来自一次真实请求或 SQL 查询；探针账号默认种子 `admin`，改过密码用 `--user/--pass`。
- 判定基线在 `scripts/progress/plan.mjs`，与 `docs/10`、`docs/08` 对应；文档变化时同步维护。
- 前置条件：数据库已启动、`pnpm dev` 已运行（API 3100 / Web 3000）。

## 4. 新环境启动步骤

1. 安装 Node.js ≥ 24、pnpm 11、Docker。
2. 复制 `.env.example` 为 `.env`，替换所有 `change_me` 与 `SESSION_SECRET`。
3. `docker compose -f infra/docker-compose.yml up -d`（PostgreSQL/Redis/MinIO）。
4. `pnpm install && pnpm db:generate && pnpm db:migrate && pnpm db:seed`。
5. `pnpm dev`；访问 `http://localhost:3000`，种子账号 `admin / JinCheng@2026`（登录后必须改密）。
6. 跑 `pnpm progress` 确认环境健康，再开始开发。
