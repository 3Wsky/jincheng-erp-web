# 锦程 ERP Web 测试用例与 UAT 签字表

## 1. 质量门禁

每次合并至少通过 lint、类型检查、单元测试和受影响模块集成测试。库存、资金、权限和迁移改动还必须通过事务回滚、幂等、并发和对账测试。

## 2. 测试层级

| 层级       | 目标                              | 最低要求                   |
| ---------- | --------------------------------- | -------------------------- |
| 单元测试   | 金额公式、状态转换、权限策略      | 关键分支与边界值           |
| 集成测试   | API、数据库事务、唯一约束、outbox | 使用真实 PostgreSQL        |
| 契约测试   | OpenAPI 与 Web/未来多端兼容       | 请求响应示例可执行         |
| 端到端测试 | 真实角色完成主链路                | 覆盖桌面和手机关键流程     |
| 迁移测试   | 映射、错误清单、重跑和对账        | 两轮全量+一轮增量          |
| 性能测试   | 查询、写入、报表和导入            | 达到 `02-验收标准.md` 指标 |
| 恢复测试   | 备份、恢复、发布回滚              | 空环境完整演练             |

## 6. 上线判定

P0 用例必须全部通过；P1 通过率不低于 95%，其余项有风险接受人和完成日期；数据不一致、越权、严重安全或无法恢复问题一票否决。
