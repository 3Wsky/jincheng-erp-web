# 锦程 ERP Web 迭代任务清单与优先级

## 1. 状态说明

- `BLOCKED`：缺少业务签字或外部条件。
- `READY`：依赖已满足，可进入开发。
- `DOING`：正在开发。
- `VERIFY`：等待测试/UAT。
- `DONE`：代码、文档、测试和验收均完成。

## 7. 每个任务的完成定义
