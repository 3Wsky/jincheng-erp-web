# 锦程 ERP Web 外部集成清单

## 1. 当前状态

所有外部集成均处于“待确认/规划”，不阻塞首店库存与采购试点，除非销售单唯一来源依赖其中某个平台。不得在未确认平台授权和数据合规前承诺可获取字段。

## 2. 平台清单

| 平台 | 目标 | 关键身份 | 方向 | 当前阻塞 |
|---|---|---|---|---|
| 管家婆/POS | 历史迁移或销售来源 | 旧系统 ID、单据号 | 导入/可能同步 | 无接口/导出样例 |
| 企业微信 | 员工、客户联系和私域归属 | userid、external_userid | 双向受控 | 主体和 API 权限 |
| 微信小程序/会员 | 会员、订单、积分和员工归因 | OpenID、UnionID、member_id | 双向受控 | 主体、隐私和现有数据 |
| 短视频平台 | 内容发布、指标和获客 | 平台账号、作品 ID | 主要拉取 | 开放平台权限和限流 |
| 直播平台 | 直播场次、时长、线索和成交 | 主播/场次 ID | 主要拉取 | 历史范围和归因字段 |
| 支付渠道 | 支付结果和对账 | 商户单号、渠道流水 | 回调/对账 | 是否由现有 POS 统一处理 |

## 3. 集成统一模型

- `external_identity`：内部对象与平台身份映射，记录有效期和来源。
- `sync_job/sync_item`：同步批次、游标、状态、重试次数和错误。
- `raw_payload`：按合规保留原始事实或摘要，限制访问和保留期。
- `outbox_event`：内部事件可靠发布；Webhook 使用验签、防重放和幂等键。
- 人工补充字段与平台事实字段分开，普通用户不能覆盖平台原始事实。

## 4. 每个平台接入前检查

1. 公司主体、应用、回调域名、授权范围和负责人。
2. 接口文档版本、字段字典、分页、限流和历史数据窗口。
3. 唯一键、更新时间、删除/撤回事件和重复推送规则。
4. 客户/员工授权、隐私告知、数据保留和导出删除要求。
5. 失败重试、死信、人工补录、重放和每日对账。
6. 沙箱、生产凭据轮换、告警和平台故障降级。

## 5. 验收要求

- 同一平台事件重复推送不产生重复业务事实。
- 断点续传和重跑不会跳过或重复数据。
- 同步失败可按平台、批次、对象查看原因并重试。
- 汇总指标可下钻到原始平台对象和内部归属记录。
- 凭据不进入 Git，日志不输出令牌、手机号明文或完整原始载荷。
