# 锦程 ERP Web 页面与菜单清单

## 1. 信息架构原则

- 桌面端承担表格、配置、审批、导入和报表；手机端优先扫码、找货、收货、调拨、待办和回访。
- 菜单只展示已授权能力，但所有数据和动作仍由服务端鉴权。
- 页面状态至少覆盖加载、空数据、无权限、业务冲突、网络失败和重试。
- 路由为草案；正式编码前需用真实角色走查原型。

## 7. 原型验收要求

- 桌面验证 1366×768 和 1920×1080；手机验证 360px 和 390px。
- 表格必须支持筛选条件回显、分页、空状态、权限字段隐藏和异步导出。
- 扫码页面必须支持键盘扫码枪与手机摄像头，连续扫码有防重和声光/文字反馈。
- 原型走查至少包含销售、店长、库管、财务四种真实角色。
